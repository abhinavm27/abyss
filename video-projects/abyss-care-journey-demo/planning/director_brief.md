# Director Brief - ABYSS Care Journey Demo

## Idea

Show the real deployed ABYSS UI completing a synthetic knee-MRI care journey.

## Viewer

Hackathon judges and the project team; they understand healthcare navigation but not the implementation.

## Promise

By the end, the viewer will understand that agents extract and explain while deterministic code owns matching, consent, and state.

## Unlocking Moment

Clarification answers become persistent ledger facts, unlocking comparison without reopening resolved questions.

## Narrative Arc

1. Hook: Ask for a knee MRI.
2. Clarification: Answer date, coverage end, and contrast.
3. Matching: Show three deterministic annual-cost paths.
4. Explanation: Nemotron explains authoritative results.
5. Consent: Approve each sandbox action separately.
6. Recap: Complete with four receipts.

## Constraints

- Duration: 55–70 seconds.
- Platform: MP4, portrait-friendly product walkthrough.
- Required examples: exact user exchange from the reported state bug.
- Avoid: medical advice, production enrollment claims, real health data.
