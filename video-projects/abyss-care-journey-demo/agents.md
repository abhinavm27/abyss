# Factory Memory

Reusable patterns for future video projects.

## General Patterns

- Start with a bounded script before building scenes.
- Define a stable base voice, then layer scene emotion without changing identity.
- Name reusable visual components in an asset registry before implementation.
- Validate understanding, audio, layout, and render health before final approval.

## Reusable Lessons

- Capture all UI states from one live session so state progression remains internally consistent.
- Verify the deployed API port is not owned by another process manager before recording.
